# 🎣 GoPhish Phishing Simulation Lab

A controlled cybersecurity laboratory created to simulate phishing campaigns for educational and cybersecurity awareness purposes.

The project was developed in an isolated virtual environment using **Kali Linux, Ubuntu, VirtualBox and GoPhish**.

> ⚠️ This laboratory was performed using fictitious credentials and authorized test users only.

---

## 🎯 Objectives

The main objectives of this laboratory were to:

- Understand how phishing campaigns are structured.
- Configure and operate GoPhish in a controlled environment.
- Create email templates and landing pages.
- Configure test users and SMTP settings.
- Execute controlled phishing simulations.
- Analyze campaign results and user interaction metrics.
- Understand the risks associated with social engineering attacks.

---

## 🧪 Lab Environment

The laboratory consisted of:

- **Kali Linux** — GoPhish server and cybersecurity environment.
- **Ubuntu** — Test workstation.
- **VirtualBox** — Virtualization platform.
- **GoPhish** — Phishing simulation framework.

All testing was performed in an isolated and authorized environment.

## 🔬 Lab Process

### 1. Environment Setup

A virtual laboratory was created using VirtualBox with separate Kali Linux and Ubuntu machines.

### 2. GoPhish Configuration

GoPhish was installed and configured on the Kali Linux environment.

The platform was used to manage:

- Test users
- Email templates
- Landing pages
- Sending profiles
- Phishing campaigns

### 3. Email Template

A controlled phishing email template was created to simulate a social engineering scenario.

### 4. Landing Page

A test landing page was configured to observe interactions with the simulated phishing campaign.

No real credentials were used during the laboratory.

### 5. Campaign Execution

The campaign was sent exclusively to authorized test users inside the controlled environment.

### 6. Results Analysis

GoPhish was used to analyze campaign metrics such as:

- Emails sent
- Emails opened
- Links clicked
- Submitted test data
- Campaign timeline

## 📊 Results

The laboratory demonstrated how phishing campaigns can be designed and monitored, as well as how user interaction can be analyzed to better understand social engineering risks.

It also provided practical experience with phishing simulation tools and cybersecurity awareness techniques.
